# Contenuti

Qui raccogliamo, in Markdown, le informazioni sugli artisti man mano che le troviamo.

## Struttura

- Un file `.md` per artista (es. `contenuti/nome-artista.md`)
- Le immagini vanno in `contenuti/immagini/`, e vengono richiamate nei file `.md` con link relativi, es.:
  ```md
  ![Descrizione](immagini/nome-file.jpg)
  ```

## Convenzioni per ogni file artista

Ogni file può seguire una struttura semplice tipo:

```md
# Nome Artista

## Biografia
...

## Opere / Brani principali
...

## Fonti
- [Titolo fonte](https://...)
```

Nessuna regola rigida per ora: l'importante è iniziare a raccogliere il materiale in modo ordinato.
